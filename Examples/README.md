# Example App

This is an example app that demonstrates how to use the SwiftIGRF package in an iOS application.

## Getting Started

1. Open `App/IGRFExample.xcodeproj` in Xcode
2. Select your target device/simulator
3. Build and run the app

## Features

The example app shows:
- Calculation of geomagnetic field values for preset locations
- Display of all magnetic field components
- Input of custom coordinates
- Date selection for calculations

## Usage

1. Launch the app
2. Select a preset location
3. Choose a date for calculation
4. View the calculated magnetic field values

The app will display:
- Input parameters (latitude, longitude, altitude, date)
- Magnetic field components (D, I, H, F, X, Y, Z)
- Secular variation values

## Requirements

- iOS 17.0+
- Xcode 16.2+
- Swift 6.0+
